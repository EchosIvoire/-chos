👻 SPECTRE, mode d'emploi

Une IA co-streameuse qui regarde ton jeu d'horreur, sursaute, commente à voix haute et lit ton chat. Tout tourne dans ton navigateur : aucune image, aucun son, aucun message ne part sur un serveur.

Démarrage express

  1. Lance ton jeu d'horreur (fenêtré ou plein écran fenêtré).
  2. Clique 🎬 Capturer l'écran du jeu, choisis la fenêtre du jeu et coche « Partager l'audio » (indispensable pour détecter les jumpscares — sur Firefox l'audio de fenêtre n'est pas partageable, préfère Chrome/Edge).
  3. C'est tout. SPECTRE analyse lumière, volume, mouvement et dominante rouge, et commente selon sa personnalité.

L'afficher dans OBS

  1. Clique 🖼️ Mode overlay : la page ne montre plus que l'avatar, la bulle et la jauge de peur.
  2. Dans OBS : Capture de fenêtre sur cet onglet, puis filtre Chroma Key si tu utilises le fond vert (spectre.html?overlay=1&bg=green).
  3. Astuce deux fenêtres : garde la page complète dans une fenêtre (analyse + réglages) et ouvre spectre.html?overlay=1 dans une autre — l'overlay se synchronise tout seul (même navigateur).

⚠️ Une « source navigateur » OBS ne peut pas capturer l'écran elle-même (le navigateur exige un clic humain) : l'analyse doit tourner dans un vrai navigateur, OBS ne fait qu'afficher.

Brancher un LLM local (optionnel)

Par défaut, SPECTRE utilise son moteur scripté : zéro installation. Pour des commentaires générés par un vrai LLM local :

  1. Installe Ollama puis récupère un petit modèle : ollama pull llama3.2:3b
  2. Autorise le site à parler à Ollama (CORS) :
# Windows (PowerShell, puis relancer Ollama)
setx OLLAMA_ORIGINS "https://thebenchlab.fr"

# macOS
launchctl setenv OLLAMA_ORIGINS "https://thebenchlab.fr"

# Linux (session en cours)
OLLAMA_ORIGINS="https://thebenchlab.fr" ollama serve

Les jumpscares sont toujours commentés par le moteur scripté (réaction instantanée) ; le LLM prend le reste. En cas de panne, bascule automatique sur le scripté.

Chat Twitch

Entre juste le nom de la chaîne : SPECTRE se connecte en lecture seule anonyme au chat (connexion directe aux serveurs Twitch, sans compte ni token). Elle réagit quand un message contient « spectre » ou !ia, et remarque quand le chat s'emballe.

Vie privée

  • Analyse vidéo/audio : 100 % locale, dans l'onglet. Rien n'est enregistré ni envoyé.
  • Réglages : sauvegardés dans ton navigateur (localStorage) uniquement.
  • Seules connexions sortantes possibles : ton Ollama local (si activé) et le chat Twitch (si activé).
