# The AI Shortcut — Kit de lancement Instagram + Ebook

Tous les assets pour lancer une page Instagram faceless dans la niche
**AI productivity & income** (marché anglais/mondial) avec un ebook à vendre.

## Contenu du dossier

| Fichier | Ce que c'est |
|---|---|
| `strategy.md` | La stratégie complète : niche, branding, funnel, chiffres, plan 90 jours. |
| `content-calendar.md` | 120 hooks prêts à filmer + planning 30 jours + structure de reel. |
| `ebook-outline.md` | Plan chapitre par chapitre de l'ebook, lead magnet et séquence email. |
| `sales.html` | Page de vente de l'ebook (style du site, en anglais). |
| `links.html` | Page « link-in-bio » (freebie → ebook → upsell + réseaux). |

## Par où commencer

1. Lis `strategy.md` en entier.
2. Crée le compte IG avec le branding de la section 2.
3. Branche Stan Store / Gumroad + MailerLite, puis remplace les
   `REPLACE_WITH_...` dans `sales.html` et `links.html` par tes vrais liens.
4. Batch tes 14 premiers posts avec `content-calendar.md`.
5. Monte le lead magnet et l'ebook avec `ebook-outline.md`.

## Liens à remplacer (placeholders)

Dans `sales.html` et `links.html`, cherche `REPLACE_WITH_` :
- `REPLACE_WITH_GUMROAD_OR_STAN_LINK` — checkout de l'ebook
- `REPLACE_WITH_FREEBIE_OPTIN_LINK` — opt-in du lead magnet gratuit
- `REPLACE_WITH_UPSELL_LINK` — page de l'upsell $47
- `REPLACE_WITH_LATEST_REEL_LINK` — dernier reel
- `REPLACE_WITH_IG_LINK` / `TIKTOK` / `YT` — réseaux

## Aperçu local

Ouvre simplement les fichiers HTML dans un navigateur, ou sers le dossier :

```
python3 -m http.server 8000
# puis http://localhost:8000/instagram-ai/sales.html
```
